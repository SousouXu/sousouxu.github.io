使用说明

如何使用

  1. 输入任意三个参数（电阻支持 K/M 缩写，如 10K、1M）
  2. 系统自动识别并置灰第四个待计算参数
  3. 点击"计算"或输满三个参数后自动出结果
  4. 已知 Vout、VFB 时，可点击"推荐标准电阻值"，并可选择 E96（1%）/E24（5%）系列
  5. （选填）填写分压电流上限，超标时会给出静态功耗提示
  6. 点击"重置参数"清空并恢复初始状态

公式说明

核心计算公式：

Vout = VFB × (RH + RL) / RL VFB = Vout × RL / (RH + RL) RH = RL × (Vout / VFB − 1) RL = RH / (Vout / VFB − 1) 分压电流 I = VFB / RL = Vout / (RH + RL)

通过调整上电阻 RH 与下电阻 RL 的比值可设定输出电压；分压电流决定该反馈网络的静态功耗，通常取值越小越省电（但抗干扰能力下降）。
