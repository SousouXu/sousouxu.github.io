使用说明

如何使用

  1. 输入任意四个参数（阻值可选单位 Ω / KΩ / MΩ，默认 KΩ）
  2. 保持恰好四个参数，系统自动求第五个并锁定多余输入框
  3. 可用组合：① B+T1+R1+T2 → R2　② T1+R1+T2+R2 → B　③ B+T1+R1+R2 → T2
  4. 点"填入示例参数"可快速体验；"重置参数"清空全部
  5. 下方"阻值—温度对应表"会随参数实时刷新

公式说明

核心计算公式：

① 由 B 求阻值：R2 = R1 × EXP[ B × (1/T2 − 1/T1) ] ② 由实测求 B：B = LN(R1 / R2) × [ (T1 × T2) / (T2 − T1) ] ③ 由阻值求温度：T2 = 1 / [ 1/T1 + LN(R2 / R1) / B ]

温度一律换算为开尔文（K = ℃ + 273.15）计算；该 B 值模型为单点近似，全温区精度有限，高精度场合建议使用规格书的分段参数或查表。
